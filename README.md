# 🐼 Panda E-commerce Website

A modern and responsive **E-commerce Landing Page** built using HTML and CSS. This project showcases products like shoes, backpacks, and accessories with a clean UI and user-friendly layout.

---

## 🚀 Live Demo

🔗 https://hoqueeprobal.github.io/panda-commerce/

---

## 📌 Features

- ✅ Responsive design  
- ✅ Clean and modern UI  
- ✅ Navigation bar with dropdown menu  
- ✅ Search bar (UI only)  
- ✅ Banner section with featured product  
- ✅ Product categories section  
- ✅ Shoes and backpack product showcase  
- ✅ Call-to-action buttons  
- ✅ Contact/Subscribe section  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Google Fonts (Poppins)  
- Font Awesome
